# Справочник телефонов завода (Telegram-бот)

Приватный бот: добавление контактов, список по цехам, поиск, редактирование и удаление. Python + aiogram 3 + SQLite.

## Быстрый поиск

Отправьте боту номер или имя без всяких команд:

- номер найден → сразу карточка с кнопками «📝 Дополнить», «✏️ Изменить», «🗑 Удалить»;
- номер не найден → кнопка «➕ Добавить этот номер», номер подставляется сам (спросит только имя и цех).

Номер сравнивается по цифрам, поэтому `8-900-123-45-67` находится и по `89001234567`, и по `+7 900 123 45 67`. Текст без цифр ищется по имени, номеру и заметке.

«📝 Дополнить» **дописывает** строку к заметке, не затирая старую; «✏️ Изменить → Заметка» заменяет её целиком.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и ALLOWED_USER_IDS
python main.py
```

## Деплой на Railway

1. Создать проект из этого репозитория — Railway соберёт по Dockerfile.
2. В Variables задать `BOT_TOKEN` и `ALLOWED_USER_IDS`.
3. **Персистентность БД:** подключить volume (например, в `/data`) и задать `DB_PATH=/data/contacts.db`. Без volume база стирается при каждом деплое.
